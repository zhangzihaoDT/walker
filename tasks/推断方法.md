## 1️⃣ 流程图（概念）

```
 ┌───────────────────┐
 │ 车型 A 用户数据    │
 │ (纯电: 性别/年龄/城市) │
 └────────┬──────────┘
          │ 统计分布 P(X|pure)
          ▼
 ┌───────────────────┐
 │ 车型 B 用户数据    │
 │ (混合: 性别/年龄/城市) │
 └────────┬──────────┘
          │ 统计分布 P_B(X)
          ▼
 ┌─────────────────────────────┐
 │ 选择方法                     │
 │ 1. 分布匹配/最小二乘法        │
 │ 2. 分类器预测概率             │
 │ 3. EM 混合模型               │
 └────────┬────────────────────┘
          │ 计算/迭代
          ▼
 ┌───────────────────┐
 │ 输出 B 用户纯电占比 p  │
 │ 增程占比 = 1 - p      │
 └───────────────────┘
```

> 核心思路：利用 A 纯电用户特征做参考，匹配 B 用户特征分布，推算比例。

## 2️⃣ Python 示例代码（分类器法）

```python
import pandas as pd
from sklearn.preprocessing import OneHotEncoder
from sklearn.linear_model import LogisticRegression

# 假设 df_a 是车型A纯电用户数据
# df_b 是车型B用户数据（性别、年龄、城市）

# 标签
df_a['label'] = 1  # 纯电

# 合并 A + B 用作特征编码（这里B没有标签）
df_all = pd.concat([df_a, df_b], ignore_index=True)
categorical_cols = ['性别', '城市']
encoder = OneHotEncoder(sparse=False, drop='first')
encoded = encoder.fit_transform(df_all[categorical_cols])

# 年龄列可以标准化或保持原样
import numpy as np
age_col = df_all[['年龄']].to_numpy()
X = np.hstack([encoded, age_col])

# 只用 A 用户训练分类器
X_train = X[:len(df_a)]
y_train = df_a['label']

clf = LogisticRegression()
clf.fit(X_train, y_train)

# 对 B 用户预测纯电概率
X_b = X[len(df_a):]
pure_prob = clf.predict_proba(X_b)[:,1]

# 估算 B 用户纯电占比
estimated_pure_ratio = pure_prob.mean()
estimated_range_ratio = 1 - estimated_pure_ratio

print(f"车型B纯电占比约: {estimated_pure_ratio:.2%}")
print(f"车型B增程占比约: {estimated_range_ratio:.2%}")
```

## 3️⃣ 补充说明

- 可以把**年龄分箱**、**城市分组**后再做 one-hot，提高稳健性
- 分类器法假设增程用户特征与纯电不同，否则估算会偏
- 如果想更精准，可使用 **EM 混合模型**，迭代更新增程分布
